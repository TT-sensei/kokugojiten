# じしょマスター

小学校中学年向けの、国語辞典のひき方を楽しく学ぶ静的Web教材です。

## 学習コンテンツ

- **じしょをひこう！**：つめ、行、はしらを手がかりに、ことばを見つける流れを練習
- **ことばならべ！**：3つのことばを五十音順に並べ、どの文字で順番が決まったか確認
- **60秒チャレンジ**：コンボとBESTを使った短時間練習
- **バッジルーム**：edu-assetsの共通・国語・エレメント・コレクションを学習記録と連動して表示
- **きろく／にがてれんしゅう**：localStorageに学習記録を保存

## 技術

HTML / CSS / JavaScriptのみで動作します。外部API、データベース、APIキーは使用していません。画像は [edu-assets](https://tt-sensei.github.io/edu-assets/) の既存バッジを参照し、GitHub Pagesで公開できます。
